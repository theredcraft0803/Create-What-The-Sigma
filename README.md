# 🛠️ Create: What The Sigma

**A massive Create modpack for Minecraft 1.21.1 (NeoForge)** — engineering, magic, farming, and exploration collide in one of the most content-packed Create experiences out there. Whether it's giant airships, submarines, cannons, or fully automated factories: if you can imagine it, you can build it here.

## ⚙️ Create, but massively expanded

The core is of course **Create** itself, expanded with a huge ecosystem of add-ons:

- **Movement & Combat:** Create Big Cannons, Create: The Air Wars, Create Aeronautics, Create Threaded Trains & Railways, Create Submarine, Create Thrusters, CBC Going Ballistic, Create Radar (incl. mobile radars)
- **Factory Automation:** Create: Ultimate Factory, Create Central Kitchen, Mechanicals, Create More Automation, Create Enchantable Machinery, Create Enchantment Industry, Create Mechanical Extruder, Petrolpark & Petrol's Parts (oil industry)
- **Decoration & Building Mechanics:** Createdeco, Create Framed, Create Connected, Create Encased, Chipped, Copycats, Colorwheel
- **Fun Stuff:** Create Chicken Nuggets, Create Mechanical Chicken, Create Dragons Plus, Create Deep Dark, Create Infinite Lava Block

## ✨ Magic & Mysticism

For anyone who wants to cast spells between the gears: **Ars Nouveau** (+ Ars Delight), **Occultism**, **Forbidden Arcanus**, and **Modonomicon** bring ritual magic, demon summoning, and arcane automation.

## 🌾 Farming & Cooking

The full **Let's Do** series (Vinery, Brewery, Herbal Brews, Beach Party, Farm & Charm, Furniture) meets **Farmer's Delight**, Greek Food, and Croptopia Delight — for anyone who wants to put down the tools and cook once in a while.

## 🗺️ Exploration & Enemies

New biomes courtesy of **Biomes O' Plenty**, additional structures and dungeons via **When Dungeons Arise**, **Additional Structures**, and **Yung's Better Nether Fortresses**, plus new creatures with **Alex's Mobs** and a clever horror system through **Torchmaster** and **Corpse**.

## 🚀 Performance & Quality of Life

Runs smoothly even on weaker hardware thanks to **Sodium**, **Lithium**, **C2ME**, **Ferrite Core**, **Entity Culling**, **Immediately Fast**, and more. For everyday convenience there's **JEI**, **Jade**, **Xaero's Minimap/Worldmap**, **Simple Voice Chat**, **Traveler's Backpack**, **Tom's Storage**, and **Storage Drawers**.
